# Your data and privacy

Review Workbench is a single-owner application bound to localhost by default.
It does not implement public multi-user hosting.

Project files contain records, decisions, summaries, evidence, discussions and
task history. Uploaded PDFs stay with the project. Keep your project folder and
Docker data volume when updating. Project exports can contain research material;
review them before sharing.

Model tasks send relevant research text to your configured provider. Literature
searches contact the selected database. Manual review does not require model requests.
Your provider's permissions and data-handling terms apply.

Store credentials only in your private `.env`. Never share that file, a personal
database, an unredacted log or Zotero authorization data. This distribution contains
no provider credentials, personal project database or original publication PDFs.

For support, describe the issue with a synthetic example and redact account and
research details. Revoke an exposed credential with its provider.
