# Using Review Workbench

## Set up a project

Create or open a project from the project menu. Define research questions, scope,
screening criteria, contribution categories and full-text summary fields in
**Research settings**. Confirm the method before submitting processing tasks.

## Search and import

Create search plans, organize concepts and synonyms, inspect the generated query
and adopt the query you want to use. Check the database hit count or run a small
pilot before formal retrieval. Hit counts, deduplicated records and included studies
are different stages and may have different totals.

You can import CSV, RIS, BibTeX and CSL-JSON independently of database access.
Choose a retrieval limit when you need a bounded run. A blank limit allows all
available results within the source's permissions and limits.

## Screen abstracts

Review titles, abstracts, decision reasons, categories and evidence. **Screen all
pending** uses the chosen search-plan scope; text filters only change the visible
list. For a filtered subset, use **Select visible** and **Screen selected**.

Existing current decisions and active tasks are skipped. Inspect unsuccessful
tasks and retry after resolving their cause. AI suggestions do not sign human review.

## Read full texts

Upload an original PDF and use **Summarize all** or **Summarize selected** for
eligible included records. Existing current summaries and active tasks are skipped.
Open **Review** to read the original beside editable summary fields, categories
and paper properties. Follow source quotations and page references when checking
claims. Saving changes and confirming verification are separate actions.

The container package uses uploaded PDFs by default. Desktop Zotero connections
need the additional setup described in the installation guide.

## Analyze and export

Choose contribution labels and search-plan scope. Set grouping instructions and
create an analysis scheme for a research perspective. Different schemes preserve
their own grouping and discussion history. Grouping and discussion requests use
the configured model and record usage.

Compare publications with their evidence. You can resize reading and discussion
columns. Save useful answers as ideas and export them with their source references.

Export a complete project package when moving or backing up your research.
Inspect exports before sharing: they can contain your research text and source excerpts.

## Language, models and cost

Use the language switch in the header. It preserves unsaved inputs and authored
research text. Discussion answers follow the requested language or the latest question.

**Models and usage** allows stage-specific model selection and custom unit prices.
Reported cost is an estimate, not a bill or a guaranteed monetary spending cap.
Confirm actual charges with your provider. Completed model output is not human verification.
